# Contributing to project-ideas

Thanks for helping the BagPack grow. Adding an idea takes about five minutes.

## What you can add

- A new formula (e.g. "Uber for X") with at least 3 example ideas
- A new example idea under an existing formula
- Fixes for typos, unclear descriptions, or wrong categories

## How to add one

1. Fork the repo and create a branch.
2. Open `README.md` and find the category where your idea fits best.
3. Add your entry in this exact format:

   ```
   - **Formula Name**: what it means in one line.
     - Example idea: short description of what it actually is
     - Example idea: short description of what it actually is
     - Example idea: short description of what it actually is
   ```

4. Open a pull request with a short title like `Add: Formula Name` or `Fix: typo in AI Products`.

## Rules

- **One idea, one place.** Don't list the same formula in two categories.
- **Keep it short.** One line for the formula, one line per example.
- **No links or promo.** Ideas only, for now.
- **No duplicates.** Search the README before adding.
- **Be specific.** "Mini Redis: an in-memory key-value store with expiry" beats "Mini Redis: a small Redis."
- **Pick the right category.** If none fits, say so in the PR and suggest a new one.

## Not sure it fits?

Open an issue first with the formula and your examples, and we'll sort it out before you write a PR.
