## Build It to Learn It

- **I Built My Own X**: Recreate an existing technology to learn how it works on the inside.
  - Git: a version control tool with commits, branches, and diffs
  - Redis: an in-memory key-value store with expiry and a simple wire protocol
  - A search engine: a crawler, an inverted index, and ranked results
- **Build from Scratch**: Implement a concept without leaning on an existing implementation.
  - Neural network: forward and backward passes written by hand, no ML framework
  - HTTP server: request parsing, routing, and responses on raw sockets
  - Database engine: storage, a query parser, and basic indexing
- **Clone X**: Recreate the key workflows of a recognizable product to understand how it's built.
  - Figma-like editor: shapes, layers, and a canvas with drag and resize
  - Spotify-like player: a music library, playlists, and a play queue
  - GitHub-like repository browser: file tree, commit history, and code viewing
- **X Lite**: Build a smaller, focused version of a complex tool.
  - Mini Redis: the handful of commands that cover most real use
  - Mini Docker-like runner: run a process inside an isolated environment
  - Mini React renderer: components, state, and a virtual DOM diff

## Marketplaces and Platforms

- **Uber for X**: Match people who need a service with people who can provide it.
  - Tutors: on-demand matching of students with nearby tutors
  - Campus rides: pool rides between hostels, campus, and stations
  - Home repairs: request a plumber or electrician and get matched
- **Airbnb for X**: Let people rent out underused spaces or assets.
  - Cameras: rent out cameras and lenses by the day
  - Textbooks: lend semester textbooks to juniors
  - Gaming PCs: rent idle rigs by the hour
- **Fiverr for X**: Connect customers with people selling a specialized service.
  - Student designers: logos, posters, and social graphics
  - Video editors: short-form and project edits for hire
  - Code reviewers: paid reviews of pull requests and side projects
- **Kickstarter for X**: Let a community fund projects or ideas.
  - Student capstones: crowdfund final-year hardware and software projects
  - Indie games: backers fund small games through milestones
  - Local community projects: neighborhood fixes funded by the people who use them
- **Shopify for X**: Give a niche of sellers the tools to create and manage storefronts.
  - Artisan shops: a storefront builder for handmade goods
  - Campus merch stores: club and fest merchandise with pre-orders
  - Digital template shops: sell resume, Notion, and slide templates
- **Booking.com for X**: Discover, compare, and reserve a particular type of resource.
  - Study rooms: find and book a quiet room by time and capacity
  - Sports courts: see availability and reserve a slot
  - Lab equipment: reserve shared instruments with usage limits

## X but for Y

- **X but for Y**: Adapt a proven product concept to a specific audience or niche.
  - Notion for students: notes, timetables, and assignments in one workspace
  - LeetCode for SQL: graded query challenges against a live database
  - Goodreads for research papers: track, rate, and review the papers you read
- **Open-Source Alternative to X**: Build a community-driven, transparent, or self-hostable alternative.
  - Trello alternative: a self-hostable kanban board
  - Postman alternative: an API client without accounts or paywalls
  - Privacy-focused notes app: encrypted notes you control
- **LinkedIn for X**: Build professional profiles and connections for a specific community.
  - Researchers: profiles built around papers and collaborators
  - Open-source contributors: profiles built from merged pull requests
  - Healthcare students: portfolios of rotations, skills, and mentors
- **Tinder for X**: Match people or resources based on preferences and compatibility.
  - Hackathon teammates: swipe by skills, stack, and interests
  - Mentors and mentees: match by goals and availability
  - Study partners: match by subject, pace, and schedule
- **Stack Overflow for X**: Create a focused question-and-answer community for a niche.
  - UiPath help: Q&A for RPA developers and learners
  - JavaScript questions: a curated, beginner-friendly Q&A
  - College course doubts: questions and answers organized by course and semester
- **Product Hunt for X**: Help a community discover and launch new things.
  - Student projects: a launch board for what students ship
  - Developer tools: daily discovery of new tools, with upvotes and comments
  - Indie mobile apps: a showcase for small apps from solo makers
- **Reddit for X**: Organize discussions into interest-based communities.
  - College subjects: a forum per subject with threads and notes
  - Local cycling: routes, meetups, and gear talk for one city
  - Indie game development: devlogs, feedback, and playtest requests

## Developer Tools

- **X for Developers**: Help developers complete a technical task more efficiently.
  - API client: send requests, save collections, and inspect responses
  - Log viewer: search, filter, and highlight large log files
  - Code snippet manager: tag, search, and sync reusable snippets
- **Developer Productivity Automation**: Automate repetitive steps in a development workflow.
  - PR summary bot: writes a plain-language summary of every pull request
  - Changelog generator: turns commits and merged PRs into release notes
  - Dependency update bot: opens PRs for outdated packages with test results
- **CLI for X**: Provide a command-line interface for a recurring task.
  - GitHub issue manager: create, label, and close issues from the terminal
  - File organizer: sort a messy folder by type, date, or rules
  - JSON formatter: pretty-print, validate, and query JSON
- **X as a Library**: Package reusable functionality for other developers to integrate.
  - Environment validator: check required env vars and types at startup
  - Retry utility: retries with backoff, jitter, and limits
  - Rate limiter: token bucket or sliding window for APIs
- **Self-Hosted X**: Let users run and control the service on their own infrastructure.
  - Pastebin: share text and code snippets with expiry
  - Analytics dashboard: privacy-friendly website stats
  - File-sharing service: upload and share files with expiring links
- **Browser Extension for X**: Add focused functionality to an existing browser workflow.
  - GitHub productivity helper: shortcuts and extra info on repo pages
  - YouTube timestamp notes: take notes pinned to video timestamps
  - Tab organizer: group, search, and snooze tabs
- **API for X**: Expose a useful capability through a documented programmatic interface.
  - Screenshot API: send a URL, get an image
  - Resume parsing API: send a resume, get structured JSON
  - Code execution API: run code snippets in a sandbox and return output

## AI Products

- **AI-Powered X**: Use AI to improve or automate a familiar workflow.
  - Resume reviewer: feedback on content, structure, and role fit
  - Lecture-to-notes generator: turns recordings into organized notes
  - Code review assistant: flags bugs, style issues, and risky changes
- **Chat with Your X**: Let users ask questions about their own documents or data.
  - Chat with PDFs: ask questions and get answers tied to pages
  - Chat with lecture slides: query a deck by topic
  - Chat with a codebase: ask how a repo works and where things live
- **AI Copilot for X**: Assist a person while they perform a task, leaving them in control.
  - Coding copilot: suggestions inside the editor
  - Writing copilot: drafting and rewriting help as you type
  - Study copilot: explanations and practice questions while you revise
- **AI Agent for X**: Have an AI system plan and execute multiple steps toward a goal.
  - Research agent: searches, reads, and compiles findings into a report
  - Issue-triage agent: labels, deduplicates, and routes new issues
  - Job-search assistant: finds listings, tailors applications, and tracks status
- **AI Workflow Builder**: Connect models, tools, and conditions into reusable AI workflows.
  - Visual agent builder: drag-and-drop nodes for models, tools, and logic
  - Document-processing pipeline: extract, classify, and route documents
  - Support-ticket workflow: summarize, categorize, and draft replies
- **AI That Turns X into Y**: Transform one kind of input into a more useful output with AI.
  - Lecture to flashcards: spaced-repetition cards from class material
  - Text to diagrams: describe a system, get a diagram
  - Resume to portfolio draft: generate a site from a resume
- **Human-in-the-Loop AI**: Let AI propose work while a person reviews consequential decisions.
  - Code review approval: AI suggests, a maintainer approves or rejects
  - Email draft approval: AI drafts, you edit and send
  - Document verification: AI extracts fields, a human confirms them
- **Local-First AI**: Keep data or model execution on-device where practical.
  - Offline document assistant: question your files without the cloud
  - Local code helper: completions from a model running on your machine
  - Private meeting summarizer: transcribe and summarize without uploading audio
- **Multi-Model AI**: Compare models or route requests to the model best suited for each task.
  - Model arena: run one prompt through several models side by side
  - AI request router: send each request to the cheapest model that can handle it
  - Response quality evaluator: score outputs from different models
- **AI Evaluation Platform**: Measure and compare the quality, reliability, or cost of AI systems.
  - Prompt regression tests: catch prompt changes that break known cases
  - Hallucination benchmark: test how often models invent facts
  - Model latency dashboard: track speed and cost across providers
- **AI Memory System**: Store and retrieve useful context across sessions or projects.
  - Personal knowledge base: searchable notes an assistant can draw on
  - Project memory: decisions and context that persist across work sessions
  - Meeting memory search: find what was said across past meetings

## Learning and Gamification

- **Duolingo for X**: Teach a skill through short lessons, streaks, levels, and feedback.
  - DSA quests: bite-sized data structure and algorithm lessons
  - SQL missions: query challenges that unlock in order
  - Networking challenges: practice routing, subnetting, and protocols
- **Learn by Building**: Teach concepts through guided, hands-on implementation.
  - Build-a-compiler course: write a compiler stage by stage
  - Interactive database lessons: build up a database one feature at a time
  - Network protocol lab: implement protocols and test them against real traffic
- **Peer-to-Peer Learning**: Let users teach, mentor, or review one another.
  - Student tutoring exchange: trade teaching time across subjects
  - Peer code review: students review each other's code with guidelines
  - Language practice matching: pair learners for conversation
- **Minecraft for X**: Offer a sandbox where users can build, explore, and experiment.
  - Visual coding sandbox: build programs by placing blocks in a world
  - Virtual electronics lab: wire up circuits without hardware
  - Modular city builder: place and connect pieces to see how a city runs
- **X Simulator**: Model a process so users can experiment with inputs and observe outcomes.
  - CPU scheduling: compare FCFS, SJF, and round robin on your own workloads
  - Network routing: watch packets move through a topology
  - Memory allocation: see paging and fragmentation as they happen
- **X Roguelike**: Turn practice into replayable challenges with randomized runs and progression.
  - Randomized DSA runs: new problem sets each attempt, with upgrades between rounds
  - Cybersecurity missions: randomized scenarios with escalating difficulty
  - Debugging dungeon: each room is a buggy program to fix
- **Procedural X Generator**: Generate structured content algorithmically from rules or inputs.
  - Maze generator: mazes from algorithms like DFS or Prim's
  - Game world generator: terrain, towns, and quests from a seed
  - Test-data generator: realistic fake data from a schema
- **Gamified Learning Platform**: Use levels, rewards, and challenges to encourage learning.
  - Operating-system quests: unlock levels by solving OS problems
  - DBMS challenges: normalization, queries, and transactions as puzzles
  - Coding boss fights: beat a large problem by clearing smaller ones first

## Productivity and Tracking

- **Personal CRM**: Track people, relationships, and follow-ups in a lightweight system.
  - Mentor tracker: log conversations and next steps with mentors
  - Networking journal: note who you met, where, and what you discussed
  - Recruiter follow-up tracker: reminders and status for each recruiter
- **Accountability as a Service**: Help people follow through using commitments, check-ins, or groups.
  - Coding streak groups: small groups that keep each other coding daily
  - Assignment check-ins: scheduled nudges and progress reports
  - Fitness accountability circles: shared goals with weekly check-ins
- **Knowledge Graph for X**: Represent concepts and their relationships as a navigable graph.
  - DSA concept map: how data structures and algorithms connect
  - Research citation graph: papers linked by citations and topics
  - Course prerequisite map: what to learn before what
- **Creator Toolkit for X**: Help a particular group create, package, and publish content.
  - Developer blog CMS: write in Markdown and publish with code highlighting
  - Tutorial builder: turn steps and code into interactive tutorials
  - Course-material generator: slides, notes, and quizzes from an outline
- **All-in-One X**: Bring related workflows into one coherent workspace.
  - Student command center: timetable, assignments, notes, and grades together
  - Developer dashboard: repos, issues, and deployments in one view
  - Creator workspace: ideas, drafts, and publishing in one place
- **X Dashboard**: Summarize important metrics and status in one view.
  - GitHub contribution analytics: activity, languages, and streaks
  - Attendance dashboard: per-subject attendance and shortage warnings
  - API health dashboard: uptime, latency, and error rates
- **X Tracker**: Record progress and show changes over time.
  - DSA progress: problems solved by topic and difficulty
  - Expenses: spending by category and month
  - Job applications: stages, dates, and follow-ups
- **X Aggregator**: Collect and normalize information from multiple sources.
  - Internship listings: one feed from many job boards
  - Tech news: stories from several sources, deduplicated
  - Open-source good-first issues: beginner issues across popular repos
- **Smart Search for X**: Find information using context, filters, or semantic similarity.
  - Source-code search: find code by meaning, not only keywords
  - Lecture-note search: search across notes and slides by concept
  - Research paper search: find related papers by topic similarity
- **No-Code X Builder**: Let users create a result without writing conventional code.
  - Form builder: drag-and-drop forms with logic and responses
  - Portfolio builder: pick a layout, add content, publish
  - Workflow builder: connect triggers and actions visually
- **Version Control for X**: Track revisions and history for artifacts beyond source code.
  - Prompt history: diff and roll back prompt versions
  - Document versions: track changes across drafts
  - Dataset revisions: snapshots and diffs of data over time
- **Digital Twin of X**: Create a digital model of a real system to inspect or simulate it.
  - Campus operations: model crowd flow, classrooms, and facilities
  - Warehouse flow: simulate stock movement and bottlenecks
  - Building energy use: model consumption and test savings
- **Recommendation Engine**: Suggest relevant items using preferences, behavior, or content features.
  - Courses: suggest what to take next from your goals and history
  - Repositories: surface projects that match your skills
  - Internships: rank openings by fit
- **Personal Operating System**: Unify personal planning, tasks, notes, and review routines.
  - Study planner: schedules, deadlines, and revision cycles
  - Personal knowledge hub: notes, links, and ideas that connect
  - Goal-and-habit workspace: goals broken into habits with weekly reviews

## Build Constraints and Challenges

- **Build X in 24 Hours**: Scope a useful prototype that can be built under a strict time limit.
  - Hackathon prototype: one core feature, demo-ready
  - Weekend API monitor: ping endpoints and alert on failures
  - One-day campus map: a simple map with key locations
- **Build X with Zero Budget**: Use free tiers and open-source tools while keeping costs transparent.
  - Free-tier SaaS: a real product running on free plans
  - Open-source study planner: self-hostable and free to run
  - Community-hosted status page: a status page with no paid infrastructure
- **Build X Without a Database**: Persist data through files, browser storage, or another deliberate alternative.
  - Local task manager: tasks stored in the browser
  - JSON-backed notes: notes saved as plain files
  - Browser-only flashcards: decks stored client-side
- **Build X Offline-First**: Keep core workflows usable without a network connection.
  - Offline notes: write anywhere and sync later
  - Flashcards: study without internet and merge progress when online
  - Field inspection checklist: record inspections in places with no signal
- **Build X from One File**: Constrain the implementation to one source file to explore fundamentals.
  - Single-file HTTP server: routing and responses in one file
  - One-file game: a complete playable game in one file
  - Compact CSV analyzer: stats and filters in one script
- **Build X Without a Framework**: Use lower-level platform APIs instead of a large framework.
  - Vanilla JS router: client-side routing with the History API
  - CSS component system: reusable components with plain CSS
  - Minimal state manager: a tiny store with subscriptions
- **Build X with One API**: Make one external API the primary source of functionality or data.
  - Weather dashboard: forecasts and alerts for chosen cities
  - GitHub analytics: insights from the GitHub API
  - Public transit viewer: live arrivals and routes
- **Build X for 100 Users**: Design a modest service around real multi-user behavior and reliability.
  - Team task board: shared boards with assignments and updates
  - Club event registration: sign-ups, capacity limits, and reminders
  - Shared notes service: multi-user notes with permissions
- **Build X, Then Benchmark It**: Measure a custom implementation against alternatives under defined workloads.
  - Custom cache vs Redis: compare hit rates and latency
  - Search algorithms: compare speed and memory on the same data
  - Image compression methods: compare size, quality, and speed
- **Rebuild X, but Faster**: Optimize a known workflow and verify improvements with measurements.
  - Fast file search: beat a naive scan with indexing
  - Image processing pipeline: speed up batch resizing and conversion
  - Large-table filtering: make filtering on huge tables feel instant

## Add an Idea

Got a formula that isn't here? Open a pull request. Keep the same format:

```
- **Name**: what it means in one line.
  - Example idea: short description of what it actually is
```

Use at least three examples per formula, and place it in the category where it fits best.

### How to turn a formula into a project

1. **Choose an audience:** students, developers, local businesses, researchers.
2. **Identify a real problem:** find a repeated frustration or an underserved workflow.
3. **Apply a formula:** use one pattern to shape the concept.
4. **Narrow the scope:** define a small, testable first version.
5. **Add a differentiator:** improve privacy, accessibility, reliability, usability, cost, or a specific workflow.
6. **Validate before expanding:** talk to potential users and check whether it actually helps.

### Idea template

- **Audience:** Who is this for?
- **Problem:** What is difficult, expensive, slow, or missing today?
- **Formula:** Which pattern are you using?
- **Solution:** What is the smallest useful product?
- **Differentiator:** Why would someone choose this over existing options?
- **Validation:** How will you know it works for real users?
